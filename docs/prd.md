# 「我要背单词」产品需求文档（PRD）

- 文档版本：V1.0
- 产品经理：许清楚
- 项目名：`woyaobeidanci`
- 产品形态：Windows / macOS / Linux / Android / iOS 跨平台学习软件
- 建议 Web UI 基线：Vite + React + MUI + Tailwind CSS；跨端容器、本地数据与同步技术由架构阶段确定
- 原始需求：一款支持自建词库与单词本、自适应复习、图词联想、跨端同步及多格式导出的背单词工具，参考成熟背词产品的交互效率，但不复制其专有内容或资源。

## 1. 产品目标

1. **形成可持续的记忆闭环**：围绕“学习—作答—复习—错词回收”安排每日任务，默认采用艾宾浩斯策略，并允许用户自定义。
2. **让词义真正可理解、可迁移**：同时提供简解、语境详解、多义项、发音与联想，覆盖英译中、中译英和混合训练。
3. **让用户拥有并理解自己的数据**：本地保存学习记录，跨端可同步、可导出，以真实来源呈现词频，以可解释反馈辅助水平评估。

## 2. 用户故事

- 作为备考学生，我希望使用四级、六级、考研英语一词库并设置每日新词、复习量和学习时段，以便按计划完成备考。
- 作为自主学习者，我希望随时把生词、错词加入自建单词本，并查看简解、语境、多义项和英美发音，以便针对薄弱点学习。
- 作为容易遗忘的用户，我希望高频错词更常出现、掌握良好的词减少出现，且能将词标记为“不再出现”，以便把精力用于未掌握内容。
- 作为多设备用户，我希望电脑和手机记住登录并同步进度，以便在不同场景无缝继续学习。
- 作为需要复盘的用户，我希望查看错词日期、次数、每日完成统计和水平建议，并导出排版良好的 Word/PDF/Excel，以便留存、打印和分享。

## 3. 需求池

优先级定义：**P0 为 V1.0 上线阻断项；P1 为 V1.0 应完成项，延期须由主理人明确决策；P2 为后续增强项。**

### 3.1 P0：核心学习与数据闭环

| 编号 | 需求 | 明确要求 |
|---|---|---|
| P0-01 | 内置与自建词库 | 至少提供四级、六级、考研英语一词库；支持自建词库、单词本，以及在学习/复习/错词页随时收藏生词或错词。 |
| P0-02 | 每日计划 | 可分别设置每日新词数、复习数及一个或多个具体学习时段；修改后明确生效日期，不静默改变已完成记录。 |
| P0-03 | 词义学习 | 每词展示简解、语境详解和各多义项；学习页必须有音标、音量、收藏、详解、英式/美式发音按钮，无音频时明确提示。 |
| P0-04 | 作答与反馈 | 默认英译中，可切换中译英、混合模式；选择题提供语义或拼写相似干扰项，可遮住中文翻译；记录正误及“认识/不认识”。答对绿色、答错红色，仅表示学习反馈。 |
| P0-05 | 复习调度 | 默认艾宾浩斯间隔；可自定义复习节点、每日数量和策略。高频错词提高出现权重，高正确率降低权重；“不再出现”立即生效并可在单词本恢复。 |
| P0-06 | 错词管理 | 错词库显示最近错误日期、累计错误次数；同一词累计错误达到 2 次及以上时，作答后明确提示累计错误数；可再次加入学习或收藏。 |
| P0-07 | 完成与历史 | 完成页展示当次新词数、复习数、学习时长；记录自动后台保存，可查询历史，不因刷新或正常退出丢失。 |
| P0-08 | 真实词频信息 | 在考研英语一语境内显示每词频率与重要性；每项须附可核验的数据集、版本、统计口径和来源链接/文献。无可靠数据时显示“未知”，不得估算冒充真实值或编造。 |
| P0-09 | 在线能力 | 支持在线释义和 AI 翻译，标明来源及 AI 生成属性；失败可重试，不影响已有本地内容和学习。网络请求不得泄露不必要学习数据。 |
| P0-10 | 本地与同步 | 本地保存词库、设置、学习及错词记录；账号登录后电脑与手机可同步，支持记住登录、退出登录和冲突提示。联网用于同步与在线服务，本地已有内容可查看。 |
| P0-11 | 导出 | 历史记录、单词本、词库均可导出 Word、PDF、Excel；含标题、字段、日期和必要分页/表头，中文不乱码，长文本不错位，Excel 数据可筛选。 |
| P0-12 | 基础体验与设置 | 黑白主界面、白底黑字；字号和音量可调；所有功能均有可见或可发现的按钮，不依赖隐藏手势；控件不得遮挡学习内容和主要操作。 |
| P0-13 | 桌面系统集成 | 提供“我要背单词”桌面图标；开机自启、最小化到托盘均为独立设置且默认不勾选，启用后可关闭并能恢复正常窗口。 |
| P0-14 | 发布与许可 | 代码采用 MIT；准备详细 README、桌面图标、Tag `V1.0` 与 GitHub Releases 发布说明。安装包按实际构建与签名能力提供，不得虚报平台产物。 |

### 3.2 P1：理解与激励增强

| 编号 | 需求 | 明确要求 |
|---|---|---|
| P1-01 | 图词联想 | 支持意义、谐音、象形三类联想；图片须原创、合法授权或合规生成，并保留来源记录，不得复制图样单词等第三方专有图片。 |
| P1-02 | 水平评估与建议 | 基于词库范围、正确率、认识率、错词及复习表现给出可解释的英语水平参考和学习建议；展示样本量与局限，不等同于标准化考试成绩。 |
| P1-03 | 提醒与跨端体验 | 学习时段触发系统通知（须用户授权）；不同设备同步每日计划、收藏和“不再出现”状态。 |

### 3.3 P2：后续增强

- 用户自定义联想图片与学习笔记模板。
- 学习趋势图表、按词表/时间段筛选的高级复盘。
- 在合法授权和隐私允许的前提下增加更多权威词典、语料库与考试词库。

## 4. 桌面与移动端 UI / 交互取舍

### 4.1 共同原则

- 主界面采用黑白层级，避免大面积彩色干扰；绿色仅用于答对，红色仅用于答错和必要错误提示，不赋予涨跌含义。
- 核心路径统一为：选词库/计划 → 学习或作答 → 即时反馈 → 完成统计 → 历史/错词复盘。
- 学习页固定保留发音、收藏、详解和作答操作；所有按钮有文字或明确图标及可访问名称，键盘、触屏均可使用。
- 适配常见桌面与手机尺寸；弹层、底部按钮、托盘菜单及系统安全区不得遮挡音标、释义、选项和提交按钮。

### 4.2 桌面端

- 使用侧栏承载今日学习、单词本、错词库、历史、词库、设置；主区域突出当前任务，详解可在侧栏或抽屉展开。
- 支持键盘作答、窗口缩放和系统托盘；开机自启与托盘默认关闭。
- 适合批量建词库、查看大表格、选择导出路径和长时间学习。

### 4.3 移动端

- 使用底部导航，学习页优先显示单词、音标、选项和主要反馈；详解放入可展开面板，不挤压作答区域。
- 使用大触控目标、英美发音独立按钮，兼容系统音量、字体缩放、横竖屏与安全区。
- 适合碎片学习和通知提醒；批量导入、复杂编辑与导出可简化步骤，但不得取消导出能力。
- iOS 不承诺与桌面相同的开机自启或托盘能力；桌面专属设置不跨端照搬。

## 5. 数据与隐私原则

- 本地数据为用户主数据，云同步须基于账号鉴权；传输加密，登录令牌安全保存，“记住登录”可撤销。
- 仅收集实现同步、在线释义和 AI 翻译所需数据；调用第三方服务前说明数据去向，敏感信息不得放入翻译或日志。
- 同步须保留字段更新时间并处理并发修改；学习事件以追加和去重为主，删除/“不再出现”等状态冲突须可恢复，不静默覆盖大量数据。
- 提供退出登录；账号注销、云端删除和本地清除在后续设计中须明确区分，避免误删。
- 水平评估只作学习参考；来源、算法版本、样本量和生成日期可追溯。真实词频与 AI 推断严格分区展示。

## 6. 资源版权约束

- 不复制、抓取后 redistribute（再分发）或绕过限制使用有道及其他产品的未授权词条、音频、图片、界面资源和数据。
- 仅参考通用交互模式，不复制有识别度的专有视觉、图标、文案、图样或品牌元素。
- 内置词库、释义、音频、联想图和语料逐项记录来源、许可证、版本及必要署名；无再分发许可的资源不得打进安装包。
- 考研英语一频率须来自可公开核验或合法授权的数据，重要性标签须说明规则；无数据标“未知”。
- MIT 仅覆盖有权开放的代码及明确列出的自有资源，不自动授予第三方词库、字体、音频或图片再分发权。
- 可使用已有技能辅助工作，但不得擅自安装技能或外部组件。

## 7. 验收标准

1. **学习闭环**：新用户能选择三类内置词库之一，设定每日新词/复习量和时段，完成一次含新词、复习、作答反馈及完成统计的任务，后台历史可复查。
2. **调度正确**：模拟同一词连续答错 2 次，错词页累计次数与最近错误日期正确并出现提示；后续调度权重提高。持续高正确率降低出现频率；“不再出现”后不再进入队列，恢复后可重新进入。
3. **内容完整**：抽查多义词可查看各义项、简解与语境；学习页音标、收藏、详解、音量及英美发音入口齐全且不被遮挡。
4. **模式可用**：默认英译中；中译英与混合模式可切换；干扰项具有相似性，遮中文功能有效，正误和认识/不认识均入库。
5. **错词与计划**：自建单词本可随时收词；每日数量和时段可编辑，完成页三项统计与历史一致。
6. **来源可信**：考研英语一频率/重要性可逐词追溯至真实来源和口径；无来源项统一显示“未知”，测试不得发现虚构数值。
7. **导出可读**：三类数据分别导出 Word/PDF/Excel，中文、长释义、多义项、日期和数字排版正确，文件可正常打开。
8. **同步可靠**：两台设备同一账号可同步词库、计划、学习、错词与收藏；记住登录有效，断网不破坏本地数据，恢复联网后不产生重复学习事件。
9. **视觉与适配**：主界面白底黑字，答对绿、答错红；常见桌面/手机分辨率下无关键控件遮挡，音量和字体设置生效。
10. **桌面设置**：全新安装后开机自启和最小化托盘均默认关闭；桌面图标名称正确，两个选项启用/关闭行为符合说明。
11. **增强能力**：图词联想三类可区分且资源来源合法；在线释义、AI 翻译失败有反馈；水平评估展示依据、样本量与建议，不宣称等同正式考试分数。
12. **发布真实**：README 覆盖安装、登录同步、数据来源、隐私、版权、导出和平台限制；Tag `V1.0` 与 Release 文件一一对应，安装包经过基本安装/启动验证。

### 平台交付边界

- **Windows**：可在本机构建、安装和验证，作为首要可交付平台。
- **Linux / Android**：需对应构建环境、依赖和签名配置；产物以实际验证结果为准。
- **macOS / iOS**：构建、签名、公证及分发受 macOS、Xcode、Apple 开发者账号和设备条件限制；未具备条件时只能提供源码与明确构建说明，不得声称安装包已生成或已验证。
- 所有平台安装包是否进入 GitHub Releases，以实际产物和验证记录为准；缺失项必须在 Release 中明示，不以占位文件冒充。

## 8. 明确假设

- V1.0 面向个人中文用户，首先服务英语考试与自学场景，不含班级管理、社交排行和付费课程。
- 初始词库内容须另行完成合法来源确认；产品名和功能需求不代表已经获得任何词典、音频或词频授权。
- 默认艾宾浩斯参数、相似干扰项生成规则及水平评估模型由设计阶段给出可解释方案，并通过测试校准。
- 同步和在线 AI 能力需要可用的服务端及第三方服务配置；无网络时保留本地学习与已有内容。
- 导出为本地生成文件，不默认上传至第三方文档平台。
- 本 PRD 不包含代码、脚手架、实际安装包或发布结果。

3. **内容与词频来源**：采用哪些具备再分发许可的词典/音频/语料来源？考研英语一词频指定哪个可核验语料集，重要性按什么公开规则分级？
4. **发布平台与签名**：V1.0 首发是否以 Windows 为必交付、其他平台按环境跟进？是否已有 Android 签名、Apple 开发者账号及 macOS 构建设备？
