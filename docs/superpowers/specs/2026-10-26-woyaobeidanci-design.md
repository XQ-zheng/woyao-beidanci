# 「我要背单词」V1.0 设计规格

- 日期：2026-10-26
- 状态：整体设计已获用户确认，待书面规格确认
- 产品名：我要背单词
- 代码许可：MIT；第三方数据、音频、图片和字体分别遵循其许可证
- 规范输入：`docs/prd.md`、`docs/architecture.md`
- 首发验收平台：Windows；其他平台按真实构建、签名和验证条件交付

## 1. 目标与成功标准

产品面向中文英语学习者，形成“选词库与计划 → 新词学习/复习 → 作答反馈 → 错词回收 → 完成统计 → 历史复盘与导出”的闭环。V1.0 必须让用户在 Windows 上安装并实际完成该流程，同时为 Android、iOS、macOS、Linux 提供同一代码基的跨端工程与构建说明。

成功不等于页面或按钮存在，而是核心数据真实持久化、调度结果可重复验证、同步不产生重复事件、导出文件可打开、资源来源可核验。未实际生成或验证的安装包不得列为已交付。

## 2. 已确认决策

1. 技术路线为 React + TypeScript + Vite，Electron 承载桌面端，Capacitor 承载 Android/iOS，共享 UI、学习核心和数据契约。
2. 采用开放词典、发音、图片资源，并提供官方授权 API 适配层；不得复制有道词典或图样单词的专有内容。
3. 图词联想采用“核心词内置合规图片，其余词提供文字联想并可由用户主动联网获取或生成、逐步缓存”。
4. 图词联想和可解释水平评估属于 V1.0；系统通知属于 V1.x，不阻塞 V1.0。
5. 匿名数据首次登录必须由用户选择是否合并；不同账号不得自动混库。
6. 自定义复习开放整数天数节点和每日数量，权重与升降级由系统管理。
7. V1.0 使用操作系统文件保护，不承诺 SQLite 静态加密；登录令牌必须使用系统安全存储。
8. Windows 默认仅当前用户安装；用户主动选择所有用户安装时才请求 UAC，应用运行本身不要求管理员权限。

## 3. V1.0 功能范围

### 3.1 词库、单词本与内容

- 内置四级、六级、考研英语一三类词库；词目、释义、音标及标签来自许可证已核验的数据源。
- 用户可创建、重命名、导入和管理自定义词库与单词本，可添加单词或短语及多个中文义项。
- 学习、复习、错词和查词页面均提供收藏按钮；收藏后可移出或恢复。
- 每词提供简解、按义项组织的语境详解、词性、音标、来源；多义词不得只显示一个释义。
- 学习页提供英式发音、美式发音、音量、收藏、详解、AI 翻译和联想按钮。音频缺失或服务失败须明确提示，不得以空白音频冒充。

### 3.2 每日计划与训练

- 每日新词数、复习数分别设置，范围各为 0–500，且至少一项大于 0。
- 支持一个或多个学习时段；计划默认次日生效，用户可明确选择应用于今日剩余任务，历史计划快照不被重写。
- 默认英译中，可切换中译英和混合模式；混合模式使用可复现的种子分配两种题型。
- 选择题默认四项，干扰项按词性、语义、拼写、前缀和长度相似度生成，剔除重复或可同时成立的答案。
- 支持遮住学习卡中文释义；提交后显示正确答案、文字反馈和正误颜色。
- 每次作答记录正误及“认识/不认识”。同一词累计错误达到两次及以上时，提示累计错误次数。

### 3.3 复习与错词

- 默认艾宾浩斯间隔为 1、2、4、7、15、30 天。
- 新词初始 `stage=-1`；第一次答对且认识后进入 `stage=0`，从该次作答起安排 1 天后复习。答错保持未入级或退一级，并安排 10 分钟后重练。
- 已进入复习阶段的单词答对且认识时先升一级，再采用新阶段间隔；答错退一级、连对清零。
- 答错权重乘 1.75，答对且认识权重乘 0.8，权重限制在 0.25–4.0；权重影响逾期任务的相对优先级，不允许绕过已到期复习。
- “不再出现”立即从新词、复习和推荐队列过滤，可恢复；恢复后已过期单词立即进入复习。
- 自定义节点为 1–365 天的严格递增整数，去重后 1–12 个；非法输入不得保存。
- 错词库展示最近错误日期、累计错误次数、所属词库和最近作答模式，可重新学习或收藏。

### 3.4 统计、历史与水平建议

- 完成页展示当次新词数、复习数和有效学习时长，并与历史记录使用同一数据源。
- 每日统计保留学习数量和具体学习时段；漏学不得生成虚假完成记录。
- 学习时长每 15 秒记录活跃心跳；页面隐藏、锁屏或窗口失焦超过 60 秒暂停，单段间隔超过 60 秒只计前 60 秒，排除长时间挂机。
- 历史可按日期、词库和训练模式查看，保留原始事件日期及时区。
- 水平评估基于最近 90 天的加权正确率、认识率、到期复习表现、错词密度和词库覆盖率。
- 至少 30 个不同单词且 60 次有效作答后给出等级；同时展示样本量、覆盖率、置信度、算法版本与局限，不宣称等同于 CEFR 或考试成绩。
- 建议必须对应最弱指标，例如清理逾期、减少新词、加强错词或增加语境练习。

### 3.5 图词联想、词频与 AI

- 联想类型包括意义、谐音、象形。每个内置词库的核心词默认选取可靠词频最高的前 50 个词，按单词去重；某词库可靠词频不足 50 个时取全部已知词并在 manifest 说明。核心词清单按词库和版本固化，清单内资源通过内容及许可校验。
- 非核心词无缓存时显示文字联想；用户主动触发后才联网获取或生成图片。离线、失败或许可不明时明确显示“暂无合规图片”。
- 图片二进制默认仅本机缓存；跨端同步文字联想及合法元数据，不同步本机文件路径。
- 考研英语一频率显示原始出现次数、统计语料、版本、来源、许可和重要性；无可靠记录时频率与重要性均显示“未知”。
- 重要性按同一已知频率词条集合的百分位划分：P90–P100 为高，P60–<P90 为中，P0–<P60 为基础；并列值采用相同百分位，未知不得当作低频。
- AI 翻译仅发送用户主动提交的文本，结果标注“AI 生成，仅供参考”，不与词典释义混排。

### 3.6 导出

- 历史记录、单词本和词库均可本地导出 Word、PDF、Excel。
- Word/PDF 使用 A4、标题、导出时间、重复表头、长文本换行和页码；PDF 必须内嵌可再分发中文字体。
- Excel 冻结首行、启用筛选、设置合理列宽和自动换行，数字保持数值类型，并防止公式注入。
- Windows 使用保存对话框；移动端通过系统保存/分享。只有实际写入成功后才报告成功。

## 4. 系统架构

采用模块化单体、local-first 和端口/适配器模式：

```text
React 页面 → Application Services → 纯 TypeScript 学习核心
                    ↓
             Repository / Provider Ports
                    ↓
       Electron IPC / Capacitor Native / SQLite / Cloud
```

- `apps/web`：共享页面、路由、组件、主题和交互，不直接执行 SQL 或持有长期令牌。
- `packages/core`：调度、队列、出题、评估、频率和冲突合并，不依赖 UI 或操作系统。
- `packages/data`：SQLite migrations、事务、Repository、outbox 和导入校验。
- `packages/services`：学习、内容、同步、账号、导出、联想和在线服务用例。
- `apps/electron`：主进程、preload、安全 IPC、钥匙链、托盘、自启和文件保存。
- `apps/mobile`：Capacitor 配置、SQLite、安全存储和系统分享。
- `packages/assets`：资源清单、版本、许可、署名和校验记录。

详细文件树、类图和时序图以 `docs/architecture.md`、`docs/class-diagram.mermaid`、`docs/sequence-diagram.mermaid` 为准。

## 5. 数据与同步

### 5.1 本地事实源

SQLite 是学习主数据，UI 状态库不是。主键采用 UUID/ULID，时间采用 UTC ISO 8601，并保留原本地日期和 IANA 时区。核心实体包括来源、单词、多义项、词库、词库单词、学习状态、学习事件、学习会话、设置、学习时段、联想、频率、同步 outbox、游标和冲突记录。

学习事件、状态更新和 outbox 必须在同一事务提交。每次作答生成唯一 `event_id`，客户端重试沿用原 ID；重复事件不得重复计数。同 ID 但内容不同必须报冲突。

### 5.2 云同步

优先使用 WorkBuddy Cloud Service 的 Auth、Database 和 LLM 模块。设计获批不代表环境已激活；编码云适配前必须通过受信界面完成激活并取得真实公共配置，再验证 Electron/Capacitor 的 Origin、登录回跳、令牌刷新、数据库游标和 LLM 调用。

同步范围包括用户自建来源、单词、多义项、词库、词库单词、联想、学习状态、事件、会话、设置和计划。上传及拉取按依赖顺序执行，公共内置内容以稳定 ID 和 manifest 版本识别，不允许账号数据覆盖。

- 学习事件追加且幂等；设置按 key 使用确定性最后写入获胜。
- 收藏、删除和“不再出现”使用带时间戳的可恢复状态及 tombstone。
- 学习状态先合并双方新事件，再按确定顺序重放；无法重放时保留冲突并提示，不能清零。
- 失败保留本地数据和 outbox，认证过期先刷新；退出登录不删除本地学习数据。
- 匿名数据合并前展示实体和冲突数量，用户确认后才上传；也可保留独立匿名空间。

不得把数据库整文件上传作为同步，不得使用 localStorage 保存学习主库或长期令牌，不得通过关闭 Web 安全策略规避 Origin/CORS 问题。

## 6. 界面与跨端取舍

- 全局白底黑字，答对为绿色、答错为红色，并同时提供文字或图标，不只依赖颜色。
- 桌面端使用侧栏：今日学习、词库、单词本、错词、历史、水平评估、账号和设置；详解使用侧栏或抽屉。
- 移动端使用底部导航、大触控目标、安全区适配和可展开详解；保留全部核心按钮和导出能力。
- 设置包含字号、音量、每日计划、复习节点、训练模式、账号同步和桌面选项。
- 开机自启、启动后最小化到托盘均默认关闭，且仅桌面端显示；托盘提供打开和真正退出。
- 常见桌面及手机尺寸下，音标、选项、详解和提交按钮不得被固定导航、弹层或底部操作区遮挡。
- 桌面支持键盘作答和批量管理；移动端优化单手操作、横竖屏和系统分享。

## 7. 内容来源与许可

1. 基础词典候选为 ECDICT，导入前核验真实仓库、具体提交和 MIT 许可证。
2. 在线详解及发音候选为 dictionaryapi.dev、Wiktionary、Wikimedia；每项保留来源和许可，不批量内置无再分发权内容。
3. 考研词频候选为 `exam-data/NETEMVocabulary`。其数据与代码许可分列，数据 CC BY-NC-SA 4.0 的非商业及相同方式共享约束必须随数据保留；未核验前不得导入。
4. 任何来源核验失败时阻止该来源进入安装包，并选用已核验替代来源；不得用伪造数据填补。词频无替代可靠来源时按规格显示“未知”。
5. MIT 仅覆盖项目代码和明确列出的自有资源；第三方资源在 `THIRD_PARTY` 清单中独立署名。

## 8. 安全、隐私与错误处理

- Electron 禁止 `nodeIntegration:true`、`webSecurity:false`，启用上下文隔离、固定 IPC 频道、DTO 校验和 sender 校验。
- 长期会话仅放系统钥匙链或经验证的移动安全存储；访问令牌尽量内存持有，日志和导出不得包含令牌。
- 第三方请求仅包含所查单词或用户主动提交的文本，不发送完整学习历史。
- 网络离线、超时、未授权、限流、内容缺失、存储不足和导出失败均有可理解提示及重试路径。
- 在线失败不删除本地缓存、不回滚已保存作答；云同步失败不阻塞本地学习。
- 清除本地数据、删除云数据和退出登录是不同操作，破坏性操作必须独立二次确认。

## 9. 测试与验收

- 核心测试覆盖首次作答 1 天到期、各复习节点、自定义节点边界、答错退级、权重上下限、错两次提示、不再出现/恢复、积压、跨时区和 DST。
- 同步测试覆盖事件幂等、同 ID 异内容冲突、任意顺序合并、tombstone 不复活、账号隔离、匿名合并及取消。
- UI/E2E 覆盖三类训练、收藏、详解、发音失败、完成统计、历史、断网恢复、字号音量、键盘与触屏、无控件遮挡。
- 导出测试覆盖中文、多义项、超长文本、分页、表头、Excel 筛选和公式注入，并用真实阅读器抽查。
- 安全测试覆盖 CSP、IPC 注入、令牌存储、退出登录和导出路径。
- Windows 验证当前用户安装、所有用户安装、取消提权、启动、托盘及自启默认关闭。
- Android、Linux 仅报告实际构建和验证结果；无 macOS/Xcode/Apple 签名条件时，macOS/iOS 仅交付源码、工程配置和明确构建说明。

## 10. 实施与发布顺序

1. 建立跨端工程、安全外壳和公共契约。
2. 实现学习核心、本地 SQLite、调度和同步契约。
3. 实现共享 UI、词典内容、账号和真实云服务适配。
4. 实现词频、联想、水平评估、导出和资源校验。
5. 完成核心及端到端测试、Windows 打包安装、图标、README、MIT、第三方许可和 V1.0 Release 材料。

GitHub 发布前必须确认目标账号和仓库；Tag 使用 `V1.0`，Release 仅附真实产物。README 必须包含功能、数据来源、隐私、安装、登录同步、导出、平台限制和从源码构建说明。Windows 提供可安装版本；Android/iOS/macOS/Linux 不以占位包冒充已验证安装包。
