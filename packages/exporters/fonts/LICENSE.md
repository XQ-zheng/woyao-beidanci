# 字体与许可

本目录包含 **Noto Sans SC（可变字重 TTF）**，用于 PDF 导出时显示中文、英文与常用符号。

- 上游项目：notofonts/noto-cjk（Google / Adobe，SIL Open Font License 1.1）
- 获取地址：`https://cdn.jsdelivr.net/gh/google/fonts@main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf`
- 文件名：`NotoSansSC-Variable.ttf`（上游为可变字重，未做子集化修改）
- 许可全文：同目录 `OFL.txt`
- 字体文件未修改、未改名，保留上游版权与许可声明。

该字体可随应用再分发。Windows 自带的 SimSun/SimHei 等系统字体不打包进项目，避免把不可再分发的字体混进安装包。
